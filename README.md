# ⏱️ Cronômetro

Aplicação web desenvolvida para praticar **HTML, CSS e JavaScript**, com foco na criação de um cronômetro interativo e no gerenciamento de múltiplos registros de tempo.

O projeto permite registrar tempos, organizar os resultados e manter os dados salvos localmente no navegador.

🔗 **[Experimentar o cronômetro](https://thiagoono.github.io/cronometro/)**

## ✨ Funcionalidades

- **Controle do cronômetro:** iniciar, pausar, retomar e reiniciar a contagem.
- **Registro de tempos:** salvar múltiplos tempos durante o uso.
- **Armazenamento local:** preservar os registros e outras informações utilizando o `localStorage`.
- **Ordenação dos registros:** organizar a lista por tempo registrado ou pela ordem dos registros.
- **Atalhos de teclado:** controlar o cronômetro e registrar tempos sem depender exclusivamente dos botões da interface.
- **Exclusão de registros:** remover tempos salvos da lista.

## ⌨️ Atalhos de teclado

| Tecla | Ação |
|---|---|
| `Space` | Inicia, pausa ou retoma o cronômetro. |
| `R` | Reinicia o cronômetro. |
| `Enter` | Salva o tempo atual e reinicia o cronômetro. |

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e apresentação da interface.
- **JavaScript:** lógica do cronômetro, interação com a página e gerenciamento dos registros.
- **LocalStorage:** armazenamento de dados no navegador.

## 🚀 Como executar

### Acessar online

A aplicação está publicada no GitHub Pages e pode ser utilizada diretamente pelo navegador:

**[Abrir cronômetro](https://thiagoono.github.io/cronometro/)**

### Executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/thiagoono/cronometro.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd cronometro
   ```

3. Abra o arquivo HTML principal em um navegador.

## 💾 Sobre o armazenamento

O projeto utiliza o `localStorage` para manter os registros e outras informações no navegador. Como os dados são armazenados localmente, eles não são sincronizados automaticamente entre diferentes navegadores ou dispositivos.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para colocar em prática os fundamentos de HTML, CSS e JavaScript por meio de uma aplicação interativa.

Durante o desenvolvimento, foram trabalhados conceitos como manipulação de elementos da página, eventos de teclado, controle do cronômetro, armazenamento local e organização de dados.
